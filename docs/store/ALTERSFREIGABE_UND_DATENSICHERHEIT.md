# Antworten für Altersfreigabe, Datensicherheit und Kinder-Richtlinien

## Google Play – „Datensicherheit“ (Data safety)
| Frage | Antwort |
|---|---|
| Erhebt oder teilt die App Nutzerdaten? | **Nein** |
| Werden Daten verschlüsselt übertragen? | Entfällt – keine Übertragung |
| Können Nutzer das Löschen von Daten anfordern? | Entfällt – nur lokal, Löschen durch Deinstallation |

## Altersfreigabe (IARC-Fragebogen)
| Thema | Antwort |
|---|---|
| Gewalt | Nein (nur Ausweichen von Hindernissen, Figur stolpert – keine Verletzungen, kein Blut) |
| Angst/Horror | Nein |
| Sexuelle Inhalte / Nacktheit | Nein |
| Sprache / Schimpfwörter | Nein |
| Drogen, Alkohol, Tabak | Nein |
| Glücksspiel / simuliertes Glücksspiel / Lootboxen | Nein |
| Nutzer-Interaktion, Chat, Teilen von Inhalten | Nein |
| Standortweitergabe | Nein |
| Digitale Käufe | Nein (nur Spiel-Münzen, kein Echtgeld) |
| Werbung | Nein |
Erwartetes Ergebnis: niedrigste Altersstufe (z. B. USK 0 / PEGI 3) – das Ergebnis vergibt IARC.

## Google Play – Zielgruppe & Familien-Richtlinie (Families Policy)
- **Zielgruppe:** z. B. 6–8, 9–12 und 13+ (Kinder sind enthalten → Familien-Richtlinie gilt).
- Erfüllt durch die App: kindgerechte Inhalte ✅, keine Werbung ✅, keine Werbe-/Analyse-SDKs ✅, keine Datenerhebung ✅, Datenschutzerklärung ✅ (muss online verlinkt sein), keine Echtgeld-Käufe ✅, kein Chat ✅.
- Vor dem Einreichen die **aktuellen** Anforderungen in der Play Console prüfen (sie ändern sich gelegentlich).

## Apple App Store (später)
- **Kategorie „Kids“** möglich (Altersband 6–8 / 9–11).
- „App Privacy“-Angaben: **Data Not Collected**.
- Kids-Kategorie verlangt u. a.: keine Werbung/Tracking von Drittanbietern ✅, Eltern-Sperre vor externen Links/Käufen (es gibt keine) ✅.

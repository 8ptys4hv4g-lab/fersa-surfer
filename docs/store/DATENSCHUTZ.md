# Datenschutzerklärung – Fersa Wave

**Stand:** 15.11.2026

Fersa Wave ist ein Spiel für Kinder und Familien. Wir nehmen Datenschutz ernst und halten es einfach:

## Kurz gesagt
**Fersa Wave erhebt, speichert und überträgt keine personenbezogenen Daten.**

## Im Einzelnen
- **Keine Konten, keine Anmeldung.** Das Spiel funktioniert ohne Benutzerkonto.
- **Keine Internetverbindung.** Das Spiel sendet keine Daten an Server – weder an uns noch an Dritte.
- **Keine Werbung** und **keine Werbe-Kennungen**.
- **Keine Analyse- oder Tracking-Dienste.**
- **Keine Käufe mit echtem Geld.** Im Spiel gibt es nur Spiel-Münzen.
- **Keine Kamera, kein Mikrofon, kein Standort, keine Kontakte.**

## Was auf dem Gerät gespeichert wird
Damit dein Fortschritt erhalten bleibt, speichert das Spiel **nur lokal auf deinem Gerät**: Punktestand/Bestwert, gesammelte Spiel-Münzen, gekaufte Surfbretter, Level-Sterne, Aufgaben-Fortschritt und Einstellungen (Lautstärke, Grafik, Sprache). Diese Daten verlassen das Gerät nicht. Wenn du die App deinstallierst, werden sie gelöscht.

## Kinder
Da keine Daten erhoben werden, werden auch keine Daten von Kindern erhoben.

## Änderungen
Wenn sich etwas ändert (z. B. eine neue Online-Funktion), aktualisieren wir diese Erklärung **vorher** und holen – wo nötig – die Einwilligung der Eltern ein.
